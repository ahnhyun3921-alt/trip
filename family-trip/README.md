# 상하이 · 항저우 가족여행

가족 5명이 같이 쓰는 여행 일정 웹앱이에요. 폰 홈 화면에 추가하면 앱처럼 열려요.

## 들어 있는 것

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 시작 | `/` | 이름 고르기. 로그아웃 전까지 그 기기에 유지 |
| 날짜별 일정 | `/trip` | 날짜 타일, 그날 중요한 것, 아래 "지금" 바 |
| 하루 | `/day/2` | 타임라인. 스크롤하면 가운데 블록이 커지고, 길게 누르면 편집(끌어서 순서 바꾸기·아래로 빼기) → AI 제안 → "정말 바꿀까요?" → 반영 + 가족 알림 |
| 블록 시트 | (하루 화면에서 블록 누르기) | 할 일 / 예약(담당자·번호·링크·캡처) / 지출 / 이동하기 |
| 이동하기 | `/move/:id` | 지도 이미지, 단계별 경로(도보·지하철), 택시 부르기, 고덕지도 열기 |
| 택시 | `/taxi/:id` | 기사님께 보여줄 중국어 카드, 디디·고덕 택시, 호텔로 돌아가기 |
| 화장실 | `/toilet` | 지금 위치 근처 공중화장실·지하철역(역내 화장실 위치까지)·쇼핑몰·패스트푸드, 와이탄 화장실 지도, 역 이름 검색(오프라인), "请问厕所在哪里？" 카드 |
| 일정 추가·수정 | `/add?day=2`, `/add?edit=:id` | 머무는 시간은 자유롭게 적기("1시간 반") → 분으로 계산 |
| 지출 | `/spend` | 날짜별·항목별 합계, 기록 |

아침 늦음 알림: 여행 날짜(`days.date`)가 오늘이고, 오전 10시 전 첫 접속인데 첫 일정 시작이 지났으면 AI가 조정안을 띄워요. 테스트할 땐 `/day/2?late=1`.

## 폴더

```
app/            화면(page.tsx)과 서버 API(app/api)
  api/ai              Claude로 일정 재배치 · 늦었을 때 조정
  api/amap/*          고덕 경로 · 근처 찾기 · 좌표 찾기 · 지도 이미지 (키는 서버에만)
components/     시트, 하단 검정 바, 토스트, 확인창, 편집 목록, AI 카드
lib/            데이터(실시간 + 기기 저장), 시간 계산, 좌표 변환, 아이콘, 가족 목록
  metro-toilets.ts    상하이 지하철 역내 화장실 (2024-10 공식 안내, 동선 근처 역만)
supabase/       schema.sql(표 만들기), seed.sql(D1~D5 예시)
public/         홈 화면 아이콘, 오프라인용 sw.js
```

## 처음 세팅 (30분 정도)

1. **Supabase** (supabase.com) 새 프로젝트 → SQL Editor에서 `supabase/schema.sql`, 이어서 `supabase/seed.sql` 실행
2. **고덕 개발자 키** (lbs.amap.com) → 应用管理에서 앱 만들고 키 추가, 서비스 플랫폼은 `Web服务`. 가입 과정에 휴대폰 인증이 필요해요
3. **Claude API 키** (console.anthropic.com)
4. `.env.example`을 `.env.local`로 복사해서 값 채우기
5. `npm install` → `npm run dev` → http://localhost:3000

## 배포

Vercel에 저장소를 연결하고 `.env.local`의 값을 Environment Variables에 똑같이 넣으면 끝이에요. 가족에게 링크를 보내고 사파리/크롬에서 "홈 화면에 추가"를 누르게 하세요.

## 중국에서 쓸 때

- 한국 로밍이나 여행용 eSIM은 대부분 해외망을 거쳐서 Vercel·Supabase·Claude가 그대로 열려요.
- 호텔 와이파이나 현지 유심에서는 막힐 수 있어요. 한 번 열어본 화면과 일정은 기기에 저장돼서 끊겨도 보이지만, 수정·AI·경로 찾기는 연결이 필요해요. 출국 전 로밍 상태로 한 번씩 다 눌러보세요.
- 고덕지도·디디 앱 열기는 폰마다 다를 수 있어서 꼭 실제 폰에서 확인하세요. 디디가 안 열리면 주소가 복사돼 있으니 알리페이 안의 디디에서 붙여넣으면 돼요.

## 직접 채워야 하는 것

- `days` 표: 여행 날짜(`date`), 날마다 호텔(`hotel`: `{"name","zhName","zhAddress","lng","lat"}`) → Supabase Table Editor에서
- 블록에 중국어 이름을 넣으면 저장할 때 좌표를 찾아서, 이동 시간과 지도가 자동으로 채워져요
