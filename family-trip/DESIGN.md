# 가족여행 디자인 시스템 v2

네 명의 디자이너가 각자 관점에서 부딪히고 합의한 결과예요.

| 역할 | 관점 | 핵심 질문 |
|---|---|---|
| 프로덕트 디자이너 | 정보 구조 | 현장에서 3초 안에 원하는 걸 여는가 |
| 비주얼 디자이너 | 브랜드·타이포 | 이 앱만의 얼굴이 있는가 |
| 인터랙션 디자이너 | 움직임·피드백 | 누를 때 무슨 일이 일어났는지 느껴지는가 |
| 접근성 디자이너 | 부모님·햇빛·한 손 | 60대가 정오에 길에서 쓸 수 있는가 |

## 1. 부딪힌 지점과 결론

- **다크 vs 밝게**: 비주얼은 전부 다크, 접근성은 야외 가독성 때문에 반대 → 두 층. 현장 층(오늘·일정·보여주기)은 밝게, 기록 층(모음·우표첩)은 다크 모눈. 남에게 보여주는 화면은 예외 없이 흰 바탕 검정 큰 글씨.
- **색**: 종류별 색 vs "지금"이 안 보임 → 색은 사진과 하늘색 하나만. 하늘색은 지금·선택됨·오늘에만.
- **우표**: 모든 카드를 우표로 vs 정보가 안 읽힘 → 우표는 해낸 것의 증표(다녀온 날, 먹은 간식, 산 기념품, 찍은 사진)에만.
- **제스처**: 숨은 동작 늘리기 vs 부모님이 못 찾음 → 숨은 동작마다 보이는 버튼 하나씩.
- **메뉴 위치**: 상단 아이콘 6개는 알아보기 어려움 → 아래 탭 4개, 글자 항상 표시.

## 2. 토큰

| 색 | 값 | 용도 |
|---|---|---|
| --ink | #111111 | 현장 층 글자, 주 버튼 |
| --text | #333333 | 본문 |
| --muted | #6B6B6F | 보조 글자 (대비 5.3:1) |
| --surface | #F4F4F6 | 카드·도구 바탕 |
| --accent | #2F97DE | 표시용 점·채움 (글자에 쓰지 않음) |
| --accent-text | #1C7DC4 | 하늘색 글자 (대비 4.6:1) |
| --d-bg / --d-grid | #0B0B0C / 흰색 6% | 기록 층 바탕·24px 모눈 |
| --d-ink / --d-muted | #F5F5F7 / #9A9AA0 | 기록 층 글자 (대비 7:1 이상) |

| 글자 | 크기/굵기 | 쓰는 곳 |
|---|---|---|
| Display | 34 / 800 | 화면 제목 |
| Title | 28–30 / 700 | 지금 카드 |
| Heading | 19–21 / 700 | 카드·시트 제목 |
| Body | 16 / 500 | 본문 (현장 층 최소) |
| Caption | 13 / 600 | 날짜·메타 |
| Show | 40+ / 800 | 보여주기 화면 중국어 |

- 간격 4의 배수, 모서리 칩 10 · 입력 14 · 카드 22 · 큰 카드 28
- 터치 영역 최소 44×44, 주 버튼 52–56
- 움직임: 상태 160ms, 시트 240ms, 우표 찍힘 320ms 스프링. 움직임 줄이기 설정이면 끔.

## 3. 컴포넌트
- 아래 탭: 오늘 · 일정 · 보여주기 · 모음. 현재 탭은 검정 + 하늘색 점
- 지금 카드: 검정 큰 카드. 지금/다음, 이름 30px, 이동하기(흰)·택시 카드(반투명)
- 도구 칸: 2열 회색 칸
- 검정 바: 탭 위에 뜬 둥근 바, 그 화면의 가장 중요한 다음 행동 하나
- 우표: 톱니 테두리. 40·64·150. 사진 없으면 도시 일러스트
- 보여주기 화면: 흰 바탕 전체 화면, 중국어 40px 이상

## 4. 단계
1. 아래 탭 + 오늘 탭 (완료)
2. 보여주기 탭 정리
3. 기록 층: 모음 우표첩, 일정 달력 우표
4. 다듬기: 우표 움직임, 빈 상태 일러스트
